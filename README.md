#gamefrom2011

Monopoly reprogramming 2011 -- electronic banking. 
WIP since August: will update on website &amp; files available here: 

The goal is to recreate the game using Arduino while polishing my rusty c++ skills :) 
---
As of October, most of the programming is done but will be uploaded later after refining it in Arduino. I took a month to learn some new functions and sharpen my c++ skills. 
Then, I learned Blender. It was difficult at first as I've only really used TinkerCAD, but it was helpful. 
I first started to wire everything on TinkerCAD so I wouldn't waste my resources, especially since some came from recycled materials. It is a literal birds nest, but I'm hoping to better my understanding of it as I further study.
